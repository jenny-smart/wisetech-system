# wisetech-system

Wisetech 合約及帳務管理系統，取代原本的「年度合約及帳務管理」與「績效及獎金報表」兩份 Excel。
以**公司（統編）**為中心，串起合約、送案、款項、寄件用印與分潤。

Streamlit + Supabase（PostgreSQL）。

## 業務流程

```
建公司（統編）
  └─ 簽合約（個案／年約／特案／募資）
       └─ 收頭款（前金，可分兩期）
            └─ 送案 → 結果
                 ├─ Pass → 依撥款金額收期中／期末 %
                 └─ Fail → 同一份合約「重寫再送」（不另收前金）
每筆入帳款項 → 依該合約的分潤設定，分給業務／主寫／管考／行政／獎金池
```

## 功能

| 頁面 | 說明 | 權限 |
|---|---|---|
| 🔎 公司查詢 | 名稱、統編、Excel 舊寫法、合約編號都能搜；新增公司 | 全部 |
| 🏢 公司資料 | 合約、款項、寄件、聯絡人、公司資料一頁看完 | 全部（業務唯讀） |
| 📄 合約總覽 | 依年度／狀態／類型／人員篩選 | 全部 |
| 📝 合約 | 送案紀錄（可重寫）、款項（發票、入帳）、合約內容、獎金設定 | 編輯：管理員、行政；獎金：管理員 |
| ✅ 待辦 | 已開發票未入帳、過案待收後續款、未過待重寫 | 管理員、行政 |
| 📮 寄件／用印 | 原「合約追蹤」 | 管理員、行政 |
| 🧾 統編確認 | 商工登記比對結果確認、手動輸入、同統編合併 | 管理員、行政 |
| 🏆 獎金績效 | 應發未發、已發紀錄、績效、歷史季獎金 | 管理員（全部）、業務（只看自己） |
| 📥 資料匯入 | 上傳舊 Excel 預覽並匯入、批次比對統編 | 管理員 |
| 👤 帳號與人員 | 帳號、角色、人員名單 | 管理員 |

## 安裝

### 1. Supabase

1. 建立專案（Region 選 Tokyo / Singapore）。
2. SQL Editor 貼上 `db/schema.sql` 全文執行（可重複執行）。
3. Connect → **Session pooler** 複製連線字串。

### 2. 本機

```bash
pip install -r requirements.txt
cp .streamlit/secrets.toml.example .streamlit/secrets.toml   # 填入 DATABASE_URL
streamlit run wiseapp.py
```

第一次開啟會要求建立管理員帳號。

### 3. Streamlit Cloud

Main file 填 `wiseapp.py`，Secrets 貼上 `DATABASE_URL = "..."`。

## 匯入舊 Excel（一次性）

從 Google Sheet 下載成 .xlsx（檔案 → 下載 → Microsoft Excel），然後：

```bash
export DATABASE_URL="postgresql://..."

# 1. 試跑：只產生 output/import_report.xlsx，不寫資料庫
python scripts/import_excel.py 年度合約及帳務管理.xlsx 績效及獎金報表.xlsx --dry-run

# 2. 打開報表確認「公司歸戶」「名稱合併」「無法解析」三個分頁，沒問題就正式匯入
python scripts/import_excel.py 年度合約及帳務管理.xlsx 績效及獎金報表.xlsx

# 3. 用公司名稱查商工登記補統編
python scripts/lookup_taxid.py
```

之後到系統「🧾 統編確認」頁處理待確認／查無的公司。

匯入規則：
- 每張含「起始日、狀態」表頭的工作表都當成年度合約表（109～115、年約）；兩列表頭與合併儲存格會自動展開。
- 公司名稱裡的註記（`(解約)`、`(for 凱景)`、`& 保密合約`…）拆到「名稱註記」，並標記解約／保密。
- 「睿元」這種簡稱若只對得到一家全名，會自動歸到同一家公司（報表「名稱合併」可檢查）。
- 民國／西元日期、`1/8 入帳` 這種沒有年份的入帳日都會轉換；無法解析的值保留原文，不會遺失。
- 兩份檔案中同編號、同公司的合約會合併成一筆。
- `--reset` 會清空所有業務資料重新匯入（帳號與人員名單保留）。

## 統編比對

使用經濟部商工登記公示資料 API（只涵蓋「公司」）：
- 名稱完全相符且唯一 → 自動帶入（狀態「自動比對」，可在統編確認頁一鍵確認）
- 多個候選 → 「待確認」，人工挑選
- 查不到 → 「查無」；行號、工作室、社團法人、學校等標為「非公司」
- 選到的統編已屬於另一家公司 → 提示合併

## 獎金

每份合約在「🏆 獎金」分頁各自設定：

| | 計算方式 | 預設 |
|---|---|---|
| 主筆過案獎金 | 過案款（期中／期末／其他）入帳金額 × 主筆 % | 5% |
| 獎金池 | 同一筆款項 × 獎金池 % | 5% |
| 績效 | 績效基數（過案金額 × 期末抽成，可手動覆寫）× 各角色 % | 依常用分法帶入，角色名稱可自訂 |

「🏆 獎金績效」頁：應發未發（勾選後登記發放日）、已發紀錄、績效統計、Excel 歷史季獎金。
業務帳號只看得到自己的資料。

匯入時會一併帶入獎金檔中「個案／天使／投抵／青艦／發放明細／獎金池」的已發放紀錄與績效分配比例。

## 專案結構

```

app_pages/              各頁面
wisetech/
  db.py                 資料庫連線
  services.py           查詢與寫入（頁面只呼叫這裡）
  parse.py              日期／金額／公司名稱／統編清洗
  excel_import.py       讀舊 Excel
  taxid.py              商工登記 API
  auth.py               登入與權限
  ui.py                 共用元件
scripts/                匯入與統編比對
db/schema.sql           資料表
tests/                  測試（pytest）
```
